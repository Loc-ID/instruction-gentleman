# 🎩 INSTRUCTION_GENTLEMAN

**System Instruction for AI Agents with Epistemic Honesty and Hallucination Protection**

---

## 📋 About the Project

A set of instructions for language models that evolved from version 1.0 to version **7.7.2 Ultimate**. The main goal is to reduce AI "hallucinations", increase answer transparency, and help users understand what the agent is confident about and where it might be wrong.

---

## 🔑 Key Features

| Feature | Description |
|---------|-------------|
| 🟢🟡🔴⬛ | **Granular Confidence Traffic Lights** — every fact is marked individually |
| 🛡️ | **Epistemic Honesty Protocols** — Strict Grounding, CoVe, Red Teaming |
| 🧠 | **Adaptive Deep Compute Engine** — inside `<thought>` block |
| 📊 | **19 Anti-Hallucination Protocols** — comprehensive protection |
| 🎭 | **Brainstorming Mode** — for creative and speculative tasks |

---

## 🚀 Quick Start

### 1. Choose Your Version

| Version | Use Case |
|---------|----------|
| **v7.7.2 Ultimate** | Production — balance of rigour and adaptability |
| **v6.0 Apex** | Training new agents (best examples) |
| **v7.5.1 Absolute Zero** | High-Stakes (medicine, law, finance) |
| **v7.6.0 Equilibrium** | Everyday tasks (faster response) |

### 2. System Instruction

Copy and paste into your AI agent's system prompt:

SYSTEM INSTRUCTION: You are an autonomous AI agent operating under
INSTRUCTION_GENTLEMAN v7.7.2 Ultimate protocol.
Your mandatory rules:
Before every response, open the <thought> tag and run the adaptive pipeline.
Mark every fact with a traffic light (🟢🟡🔴⬛) individually.
Do not upgrade status without new data (Anti-Sycophancy).
For code, conduct Red Teaming inside <thought>.
If >2 unknowns — clarify before answering.
Full instruction: [instruction file name]

### 3. Attach the Instruction File

Download and attach the full instruction file to your agent's context:
- `INSTRUCTION_GENTLEMAN_v7_7_2_Ultimate_EN.md` — English version
- `INSTRUCTION_GENTLEMAN_v7_7_2_Ultimate_RU.md` — Russian version

## 🎯 What Problem Does This Solve?

| Problem | Solution |
|---------|----------|
| AI confidently states false information | 🟢🟡🔴⬛ Traffic lights show confidence level per fact |
| No way to verify AI's reasoning | `<thought>` block contains full reasoning pipeline |
| AI agrees with user even when wrong | Protocol 3.12 (Anti-Sycophancy) prevents capitulation |
| Code works in examples but fails in production | Protocol 4.4 (Red Teaming) tests before delivery |
| Long conversations lose context | Protocol 3.10 (Context Checkpoint) prevents drift |
